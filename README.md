# SoccerRecruitmentComping

## Main Idea

The proposed project aims to answer: “Which player seasons have produced a statistical profile most like the transfer target in a comparable role?”

It aims to give a starting point for player evaluation that is easy to understand and measure, rather than creating metrics or implied transfer value
that provide an inconsistent scale 

The data used is season-level player data from seasons 21-22 to 25-26

## Steps
Clean and normalize data regarding duplicate rows, team names, and player names

Define a minimum minutes cutoff regarding sample size availability 

Create role-specific features and axes regarding different positions 

Normalize for role and league 

Calculate team share 

Build multi-season profiles and distances

Bonus: Ideate backtesting
